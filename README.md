# Week 1 — Python Basics and Game Statistics Analyzer

## Overview

During Week 1, I learned the basics of Python by building a small game statistics analyzer.

The project started with basic Python syntax and data structures and gradually moved toward reading data from a CSV file, calculating statistics, and exporting results to JSON.

## What I Learned

During this week I practiced:

- Python variables and printing
- Lists and dictionaries
- `for` loops
- `if` / `else` conditions
- Functions and return values
- Handling division by zero
- Reading CSV files
- Using `csv.DictReader`
- Converting strings into numbers
- Handling missing data
- Writing JSON files
- Working with file paths
- Using a Python virtual environment
- Git commits and pushes

## Project

The final project analyzes game-session data stored in a CSV file.

The dataset contains information such as:

- Game ID
- Session duration
- Kills
- Deaths
- Accuracy
- Win/Loss result
- Reaction time

The analyzer calculates:

- Total games
- Average kills
- Average deaths
- Average accuracy
- Best game
- Worst game
- Number of missing accuracy values
